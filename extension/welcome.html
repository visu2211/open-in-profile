Welcome to Open Tab in Profile

One quick setup step, then you're ready to send tabs between profiles.

Why an extra step? Chrome doesn't let any extension open or list other browser profiles on its own — that's blocked for privacy reasons, for every extension, on every browser. This extension pairs with a tiny local helper program to do that part. It runs entirely on your Mac and never talks to the network.
1

Download the helper

Get the project from GitHub. You only need the host folder, but downloading the whole thing is easiest.

Download from GitHub
2

Run the installer

Unzip the download, open Terminal, and run:

cd open-in-profile-main/host
./install.sh

This installs a small script that only Chrome can talk to, and registers it so this extension can find it.

3

Fully restart Chrome

Quit Chrome completely with ⌘Q (not just closing the window), then reopen it. Chrome only checks for new native helpers when it starts up.

4

You're set

Click the toolbar icon on any tab — your other Chrome profiles and Incognito will show up. Shift-click multiple tabs first to send them all together, or right-click a page for the same list.

Head to Settings from the popup to tell the extension which profile is "you," so it's left out of the list.

Good to know

Is this safe?

The helper never makes network requests. It only reads your local Chrome profile list and opens tabs using Chrome's own open command. Full source is on GitHub.

What platforms are supported?

macOS only for now. The installer and helper shell out to macOS's open command.

Something's not working

Double check the helper was installed (step 2) and that you fully quit and reopened Chrome (step 3) — that combination fixes almost every setup issue. Full troubleshooting is in the GitHub README.
